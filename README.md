# Neon Runner Game by Kratika

A futuristic neon-themed runner game where the player escapes system failures and survives against obstacles.  
Built as a creative project to explore game design basics and showcase coding skills.

---

## 🎮 Features
- Neon glowing interface with AI-inspired theme  
- Score tracking system  
- Restart option after system failure  
- Increasing difficulty with levels  

---

## 🕹️ How to Play
1. Press **START / RESTART** to begin.  
2. Control the blue square to avoid red obstacles.  
3. Survive as long as possible to increase your score.  
4. If "NEON FAILURE" appears, restart and try again.
